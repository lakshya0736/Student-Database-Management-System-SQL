# Student Database Management System - SQL

## Project Overview

Student Database Management System is a SQL-based project developed to store, manage, and analyze student information using relational database concepts.

## Features

- Database creation
- Student record management
- Insert student data
- Update records
- Delete records
- Search student information
- Data analysis using SQL queries

## Technologies Used

- SQL
- MySQL

## SQL Concepts Used

- CREATE DATABASE
- CREATE TABLE
- INSERT
- SELECT
- UPDATE
- DELETE
- WHERE clause
- ORDER BY
- GROUP BY
- Aggregate Functions
- Primary Key
- Constraints

## Database Table

Students table contains:

- Student ID
- Name
- Email
- Age
- Department
- Marks

## Learning Outcome

This project helped me understand relational database design, writing SQL queries, managing structured data, and performing data analysis using SQL.
